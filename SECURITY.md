# Política de Seguridad

## Reportar una Vulnerabilidad

Tomamos la seguridad de `obs-ai-workflow` muy en serio. Si descubres una vulnerabilidad de seguridad, por favor repórtala de manera responsable.

### Cómo Reportar

**NO** uses el issue tracker público para reportar vulnerabilidades de seguridad.

Envía un email a: **nelson.e.laguna.r@gmail.com**

**Incluye en tu reporte:**
- Descripción de la vulnerabilidad
- Pasos para reproducir
- Versión afectada
- Posible impacto
- Sugerencias de fix (opcional)

### Qué Esperar

1. **Confirmación de recepción**: Respondemos en 48 horas
2. **Evaluación**: Analizamos el reporte en 5 días hábiles
3. **Desarrollo de fix**: Trabajamos en una solución
4. **Publicación**: Lanzamos parche y advisory de seguridad
5. **Reconocimiento**: Creditos al reportero (si lo desea)

### Políticas de Divulgación

- No divulgamos detalles hasta que haya un parche disponible
- Coordinamos con otros proyectos afectados si aplica
- Publicamos advisory en GitHub Security Advisories

## Buenas Prácticas para Usuarios

- Mantén `obs-ai` actualizado a la última versión
- No compartas tus API keys (OpenAI, Anthropic, etc.)
- Usa contraseñas seguras para OBS WebSocket
- Revisa permisos de la aplicación
